Process

작업 순서

  1. 1문의양식을 복사해 문의글로 보내 주시면 일정과 가능 여부를 안내합니다.
  2. 2아트머그 결제일정 확인 후 아트머그에서 결제합니다.
  3. 3디스코드 상담취향과 참고 자료를 통화로 꼼꼼히 확인합니다.
  4. 4성형작업 후 컨펌을 진행합니다.
  5. 5페이셜작업 후 컨펌을 진행합니다.
  6. 6파일 전달작업을 마친 뒤 FBX 또는 VRM 파일로 전달합니다.

전달 파일 · FBX / VRM

가능하면 FBX로 받아 두시는 것을 추천합니다

대부분 VRM을 찾으시지만, FBX가 훨씬 보존성이 좋은 원본 파일입니다. 나중에 의상 작업을 하실 때도 얼마든지 수정할 수 있고 VRM으로 변환하기도 쉽습니다.
